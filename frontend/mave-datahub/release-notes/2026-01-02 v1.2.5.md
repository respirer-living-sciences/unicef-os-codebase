# Release Notes – v1.2.5

_Released on 2026-01-14_
Author: Afzal Mohamed

## ✨ Changes

Highlights:

Updated device data fetching to handle new faster API response format.

Added a transformer to convert API data to GeoJSON, automatically including new pollutants.

Renamed pollutant keys (pm25 → pm2.5cnc, pm10 → pm10cnc) for consistency.

Optimized performance for large device lists using useMemo.

Enhanced Map UI:

Added cursor pointer on clusters and markers.

Created a slick pollutant dropdown selector component.

Added a reusable summary card overlay for the map.

Improved popup handling for markers.

Git deployment guidance added: server can now safely sync with main branch using git reset --hard origin/main.

Improvements:

Future-proofed pollutant handling for additional metrics like CO2.

Memoized transformed data to reduce re-renders and improve map performance.

Clean, reusable MUI components for dropdowns and map overlays.

Bug Fixes:

Handled undefined features on map click to prevent runtime errors.

Improved popup behavior for overlapping clicks on unclustered markers.
