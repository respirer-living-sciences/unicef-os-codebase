# Release Notes

_Released on 2026-04-15_
Author: Afzal Mohamed

## ✨ Changes

Highlights:

* **Granular Loading States:** Replaced the global table loading skeleton with refined row-level skeletons in the `SortableTableComponent`. This provides a smoother transition during data fetching and maintains the visual structure of the dashboard.
* **Chart UX Optimization:** Implemented a dedicated Skeleton loader for the `AdvancedLineChart`. 
* **Smooth Interaction Design:** Fixed a layout shift issue where the page would abruptly scroll back to the top when a graph finished rendering. By enforcing a `minHeight` on chart containers, the dashboard now maintains consistent scroll positioning.
* **Enhanced Discoverability:** Added interactive tooltips to table rows that appear when charts are available for plotting. 
* **Code Quality & Architecture:**
  * Synchronized loading states across the `Outline` and `Mave-Datahub` micro-frontends to ensure a unified user experience.
