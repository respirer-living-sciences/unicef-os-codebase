# Release Notes

_Released on 2026-07-08_
Author: Afzal Mohamed

## ✨ Changes

This release introduces a major performance optimization to the application boot time and route transitions, switching the micro-frontend integration strategy from static to dynamic remote loading at runtime, alongside visual consistency improvements for loading states.

### Highlights:

* **Dynamic Micro-Frontends Integration (Module Federation):**
  * Migrated from static webpack configuration remote entries to fully dynamic runtime loading via script injection (`loadRemote.js`).
  * Instead of loading all `remoteEntry.js` bundles on boot, remotes are loaded lazily on demand when their respective components mount.
  
* **Drastic Page Load Performance Improvements:**
  * Reduced Largest Contentful Paint (LCP) from **6.27 seconds** to **1.51 seconds** (~75.9% reduction) by eliminating blocking remote loading at startup.

* **Unified Loading State UX:**
  * Replaced default text `"Loading..."` boundary states across all main pages (`Analytics`, `Map`, `Comparison`, `Devices`, `Calendar Heatmap`, `Download`, and `Privacy Policy`) with the new visual fallback spinner overlay.
