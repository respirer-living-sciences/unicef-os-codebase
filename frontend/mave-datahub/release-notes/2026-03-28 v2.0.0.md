# Release Notes

_Released on 2026-04-14_
Author: Afzal Mohamed

## ✨ Changes

Highlights:

* **Unified Modern UI** Applied a centralized Material-UI theme featuring rounded corners, custom soft backgrounds, and signature teal (`#03C9D7`) focus states to all inputs, dropdowns, and buttons. 
* **Sleek Component Upgrades:** Redesigned cards with slick minimal gradients and hover-lift animations. 
* **Calendar Heatmap Redesign:** Modernized the calendar layouts into crisp white tile grids. 
* **Loading Skeletons:** Replaced the loading gif with a grid skeleton in the calendar heatmap, and added skeleton placeholders for the graphs in the Comparative Analysis component.
* **Chart Labels:** Updated the Comparative Analysis chart legend to display the device's location name instead of just IMEI.
* **Component Refinements:**
  * Fixed an issue where header font sizes were locked at 14px.
  * Redesigned and modernized the selectors in the compare component to match the standard Material-UI styling.
* **Data Download Tool:** Completely redesigned the tool's layout into a clean, multi-card format with standard icons and helper sections, preserving all existing functionality.
