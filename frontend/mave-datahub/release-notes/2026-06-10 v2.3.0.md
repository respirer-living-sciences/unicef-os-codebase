# Release Notes

_Released on 2026-06-10_
Author: Afzal Mohamed

## ✨ Changes

This release focuses on multi-app theme propagation and map visual correctness.

### Highlights:

Theme Mode Propagation:
  Implemented dark/light mode synchronization from the core shell (`mave-datahub`) to remote micro-frontends.
  Added switch on app bar to toggle dark/light mode.
  Updated `data-download-tool` and `device-management` MFE components to receive and apply the shell's active `themeMode` via a local dynamic `ThemeProvider`.
  This resolves Module Federation context-sharing limitations for `@mui/material`.

Monitor Status Bug Fix in Map:
  Corrected status reporting for monitors on map markers and popups.
  Previously, offline monitors were displayed as "Active".
  Now correctly labels monitors as "Online" or "Offline" and shows grey circular stroke marker color for offline monitors based on device data status.
