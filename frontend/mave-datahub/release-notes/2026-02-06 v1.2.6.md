# Release Notes – v1.2.6

_Released on 2026-02-06_
Author: Deepak Kumar

## ✨ Changes

Resolved data caching inconsistencies between backend and frontend
Fixed an issue where updates or corrections applied to device data at the backend were not being reflected on the frontend due to caching behavior, resulting in stale data being displayed to users.

Improved aggregation logic on the Home page
Updated the Home page aggregation logic from a rolling 24-hour window to a calendar-based 1-day aggregation, ensuring more accurate and semantically correct data representation.

## Notes:

These changes improve data accuracy and consistency across the platform.

The caching fix ensures that frontend views always reflect the latest backend-processed data.

Aggregation logic updates align the UI behavior with standard data analytics practices.

Changes were implemented with minimal impact to existing user workflows.
