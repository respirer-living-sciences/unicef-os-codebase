# Release Notes

_Released on 2026-06-23_
Author: Afzal Mohamed

## ✨ Changes

This release introduces a new regression analytics chart component, UI visual adjustments, and dark mode readability fixes.

### Highlights:

* **Regression Mixed Chart Component:**
  * Created a dedicated React component (`RegressionMixedChart.jsx`) replacing the old static image scatter plot with interactive scatter plot chart for regression analysis.
* **Table Null Value Bug Fix:**
  * Added safety checks in `SortableTableComponent.jsx` to prevent null values from being incorrectly converted and displayed as `0.0`.
