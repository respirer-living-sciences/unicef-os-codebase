# Release Notes

_Released on 2026-05-07_
Author: Afzal Mohamed

## ✨ Changes

This release focuses on enabling real-time push notifications.

### Highlights:

Firebase Cloud Messaging (FCM) Integration:
  Implemented browser-native push notifications using Firebase.
  Added a dedicated firebase-messaging-sw.js service worker to handle background notifications even when the app is closed.

Smart Notification Syncing:
  Created a NotificationSyncer component to automatically register and sync FCM tokens with the backend API (/sync-login-token).
  Integrated logout syncing to safely remove tokens when a user signs out, preventing orphan notifications.

Architectural Session Management:
  Moved the notification logic to the core shell component (MaveDatahub.jsx). This ensures the notification listener starts once upon login and remains active throughout the entire session, regardless of navigation between different micro-frontends.

Deployment & Build Optimizations:
  Webpack Build Pipeline: Integrated copy-webpack-plugin to automatically include the Firebase service worker in the production build.

Note:
  Push notifications are automatically triggered by the backend monitoring system. When pollutant levels exceed predefined safety thresholds in the last 15minutes, the system will instantly dispatch an alert to registered devices, ensuring real-time awareness of air quality changes.
